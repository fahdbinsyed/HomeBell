# Future Feature Hooks

Nothing here is implemented in the MVP beyond the listed structural hooks.

| Feature                              | Hook now                                                                                                                                                                           | Later                                                                                                                    |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Audio announcements**              | feature key `audio.announcements` (default false); queue events already carry the display name + class label needed; `IAnnouncementSink` interface reserved in Dismissal.Contracts | display app subscribes and speaks (cloud TTS or on-device), per-tenant voice settings                                    |
| **QR verification / staff scanning** | `PickupRequest.verificationMethod` (enum `none` only in MVP) and `VerificationMethod` enum in contract reserved; `PickupAcknowledgment` separate from request state                | gate staff app scans guardian QR → `verified_handoff` acknowledgment; _only then_ may marketing mention verified handoff |
| **iOS**                              | _Not a future hook — iOS ships in the MVP together with Android (ADR-0017)._                                                                                                       | —                                                                                                                        |
| **Stronger device identity**         | `DeviceRegistration.publicKey`, `attestationStatus`; `X-Device-Signature` header reserved in contract                                                                              | Android Keystore + Play Integrity and iOS Secure Enclave + App Attest, signed requests — on both platforms               |
| **Multi-campus**                     | `Campus` entity; nullable `campusId` on Student, PickupRequest, DisplayDevice; display `zone`                                                                                      | campus switcher, per-campus windows/geofences/queues                                                                     |
| **Enterprise billing / groups**      | `Tenant.dataPlacement`, plan versions, `TenantSubscription.billingReference`                                                                                                       | tenant groups, consolidated invoicing, dedicated DB placement, SSO (`sso.enterprise`)                                    |
| **Multilingual**                     | all UI strings via i18n keys from Phase 1; `UserAccount.locale`; RTL-safe layouts                                                                                                  | translations, per-tenant default locale                                                                                  |
| **Bus module / advanced analytics**  | queue events are a durable, sequenced stream suitable for analytics export                                                                                                         | separate modules                                                                                                         |
